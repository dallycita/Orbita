# Material de trabajo

Nada de esta carpeta forma parte del juego (el juego es solo `index.html`). Se guarda como referencia.

- `prototipos/`: versiones tempranas del juego, en un solo archivo HTML cada una.
- `diseno/`: imágenes de diseño (íconos, pantallas de misiones, pruebas visuales).
- `musica/`: grabaciones de prueba de la banda sonora "Horizonte de sucesos".
